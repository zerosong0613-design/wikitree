# CODEX 판단 위키

팀의 판단을 **누가·언제·왜 정했는지까지 남는, 기계가 읽는 지식 계층**으로 쌓는 **로컬 웹 앱**.

지식은 계약에서만 나오지 않는다. 자문·회의·사고·규제·내부규정도 판단의 원천이다. 판단 하나에 여러 축(판단·원천·의뢰부서·주제)을 태그로 달고, 위키는 축을 바꿔가며 같은 데이터를 다른 관점으로 본다.

구조 원칙과 스키마는 저장소 루트의 `CLAUDE.md`(마스터 계획서)에 있다. **그 문서가 헌법이다.**

## 실행

```bash
npm install
npm run dev
```

`http://localhost:5173` 이 열린다. 백엔드 없음 — 순수 브라우저 SPA.

## 화면

**위키가 곧 앱이다.** 별도 프레임 없이 3판 그리드로 동작한다.

- **좌 25% 목차** — 지도. 상단 축 토글 `[판단별] [계약서별] [부서별] [원천별]` 로 같은 데이터를 재그룹핑한다. 판단별은 집계(같은 판단을 묶어 관철/양보), 계약서별은 나열(계약군 > 계약종류 > 조항 순).
- **중 50% 룰 페이지** — 읽고 쓰는 자리. 각 필드가 마우스오버로 바로 편집된다.
- **우 25% AI 찾기** — 물으면 트리에서 답하고 근거와 저작자를 밝힌다.

## 쓰는 법

1. 우상단 **⚙ 설정** → Anthropic API 키 + **내 이름** 입력 → 저장. (새로고침해도 유지됨)
2. **[카테고리 설정]** → 판단·원천·의뢰부서 3축을 먼저 정한다. 프리셋 시드가 있고 자유롭게 편집한다.
3. **[지식 넣기]** → 판단문을 쓰고 축을 고른다. `[AI에 축 제안]` 을 누르면 AI가 4축을 초안으로 채우고, 사람이 확정한다.
4. **[…더보기]** → 계약 마이닝(대량 부트스트랩)·검토 추출 등 무거운 입구.
5. **[md 저장]** → 사람이 읽는 위키 + 말미의 기계 판독용 JSON을 한 장으로 내보낸다.

## 원칙

- **카테고리는 사람이 먼저 정한다.** 판단·원천·의뢰부서는 닫힌 축 — AI는 사람이 정한 목록 안에서만 고른다. 주제만 열린 축으로 AI가 자유롭게 단다.
- **AI는 초안, 사람이 확정.** 확정한 사람이 그 판단의 저작자다.
- **주인 없는 판단은 트리에 넣지 않는다.** 모든 편집이 `authors`·`history`에 자동 stamp되고, 룰 페이지 `[역사]` 에서 확인한다.
- **트리는 저장이 아니라 뷰다.** 룰은 평면 배열로 저장하고, 축으로 그때그때 그룹핑한다.
- **로컬 전용.** 데이터를 밖으로 내보내지 않는다.

## 판단의 강도

등장 빈도가 아니라 **판단의 성격**으로 가른다. 둘을 절대 뒤섞지 않는다.

- `마지노선(hard)` — 양보한 적 없는 선.
- `협상 여지(soft)` — 양보 이력이 있는 조건.
- `신규·미확정(neu)` — 표본이 적거나 최근 등장한 쟁점.
- `사람 확인(hold)` — 팀 판단이 갈린 것. 확정과 섞지 않는다.

## API 키 안전

- 키는 **브라우저 `localStorage`(`codex_api_key`)** 에만 저장된다.
- 코드·레포·`.env` 어디에도 하드코딩하지 않으며 커밋하지 않는다.
- 브라우저에서 `https://api.anthropic.com/v1/messages` 를 직접 호출한다
  (CORS용 `anthropic-dangerous-direct-browser-access: true` 헤더 사용).

## 저장소

- `codex_tree` — 룰 평면 배열.
- `codex_categories` — 3축 카테고리(v2 형식). 사용자 소유이며 AI는 읽기만 한다.
- `codex_api_key` — API 키.
